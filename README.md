# 简单介绍一下这款游戏
我是编程小白，这是纯AI制造的休闲小游戏，由于对AI不太懂，编程也不太懂，只有网上看教程。教程也看不太明白。/n
索性，安装按照网上步骤把AI装下来。然后就是各种尝试。折腾了2个月后，DSH出来了，想着试一把，想着写小说，发现很拉跨！写的东西都要改。/n
改得心烦，刷手机，发现AI能做游戏。果断，暂时停下写小说，网上查攻略，最后发现DSH无法识别图形，于是就有了这款文字挂机类型的游戏。/n
既然能做出来，就做一款自己觉得好玩的挂机休闲小游戏吧，反正自己之前也经常玩。/n
内容会不断的更新，但是很多的东西不完善。/n
没有任何美术资源，场景、角色、怪物、UI全部是程序弄的。/n
没有音效资源，所以无声。/n
玩法逐步完善。毕竟主要是根据我写的小说内容来做的。世界观肯定没啥问题的。/n
最后，有大佬看中这个，一起优化不？/n
